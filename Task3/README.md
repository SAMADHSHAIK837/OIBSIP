# OIBSIP Data Analytics - Task 3

## Objective

Clean and transform a deliberately messy dataset into a clean and analysis-ready dataset.

## Tools Used

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Data Cleaning Performed

- Checked missing values
- Identified and removed duplicate rows
- Standardised inconsistent formatting
- Corrected data types
- Detected numeric outliers using the IQR method
- Handled missing values using appropriate strategies
- Created a before-vs-after data quality summary
- Saved the cleaned dataset as a new CSV file

## Outcome

The dataset was successfully cleaned and transformed into an analysis-ready dataset.
